# Training Day Games

Registration and competition-management platform for the Training Day Games.

## MVP
- Event landing page
- Division selection
- Athlete registration
- Waiver acceptance
- Stripe Checkout
- Stripe webhook payment confirmation
- Organizer registration dashboard
- Leaderboard foundation

## Stack
- Next.js + TypeScript
- PostgreSQL + Prisma
- Stripe
- Vercel-ready

This repository is the persistent master codebase for the Training Day Games platform.
